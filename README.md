# OMNI-SAAS: Global Intelligence & Executive Briefing Portal (Micro-SaaS)

Modern Next.js 14+ Micro-SaaS client portal for the OmniIntel platform. Provides non-technical corporate executives, PR firms, and analysts with real-time sentiment telemetry, executive briefing extraction, and API key management.

## 🌟 Features
- **Live Intelligence Search**: Multi-source querying powered by the backend OMNI-API engine.
- **Sentiment & Adverse Risk Scorer**: Instant tone classification and risk percentage calculator.
- **Executive Digest Generator**: Automatic summarization of long-form reports into high-impact bullet points.
- **Dual Stream Monetization**: Integrated pricing tables for Free ($0), Business Pro ($49/mo), and Enterprise ($199/mo).

## 🚀 Running the Portal

```bash
# Install dependencies
npm install

# Start Next.js development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
